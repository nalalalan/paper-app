# sarrus.aolabs.io

This checkout deploys the public Sarrus site at `sarrus.aolabs.io`.

GitHub Pages serves the `gh-pages` branch from the repository root. The `CNAME`
file points the site to `sarrus.aolabs.io`.

Paper PDFs live at the site root:

- `topology-programmable-soft-robotic-surfaces-and-bodies-full.pdf`
- `topology-programmable-soft-robotic-surfaces-and-bodies-science.pdf`
- `topology-programmable-soft-robotic-surfaces-and-bodies-science-supplementary-notes.pdf`
