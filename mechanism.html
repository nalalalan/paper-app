Sarrus mechanism proof

One public artifact for inspecting the mechanism behind programmable soft robotic surfaces and bodies.
Mechanism Monolithically printed pneumatic Sarrus-linkage-inspired cell with compliant links, flexural joints, and integrated PneuNet actuation.
Assembly Four cells form a 2 x 2 module with cross-cell pneumatic channels and snap-fit module connectivity.
Function Local pressure-driven expansion and module bias produce programmable shape, stiffness, surface waves, object manipulation, crawling, and rolling.

mechanical path

Geometry, constraints, and load path

  • The unit cell uses a compliant Sarrus-linkage-inspired geometry so pressure-driven expansion rotates linkage legs while the soft pneumatic actuator drives deformation.
  • The cap reduces top-surface gaps between adjacent cells; module-scale leg orientation creates a repeatable bending bias.
  • The public mechanical characterization includes pressure-dependent expansion, force-displacement response, hysteresis, and local stiffness for cells and module arrays.

prototype state

Build, actuation, and iteration

  • The physical module is a printed pneumatic prototype, not a speculative rendering.
  • The actuation assumption used in the public paper is tethered pneumatic input; integrated electronically addressed actuation remains future work.
  • The current reviewer-visible limitation is source coverage: the public page now exposes the mechanism evidence in HTML, while detailed numeric extraction still belongs in the manuscript and supplementary figures.

physical experience

From mechanism to believable motion

  • The WDI-relevant reading is not just a soft robotics cell; it is a controllable physical behavior primitive.
  • A surface or body can visibly change shape, move an object, generate a travelling wave, or produce a character-like body motion from the same repeated module architecture.
  • The current strongest show-value example is object manipulation: the body lowers around an object, grasps it, transports it through a curved posture, and releases it elsewhere.

source coverage

What a reviewer can inspect now

  • HTML-visible evidence: mechanism summary, constraint/load-path description, actuation assumption, build state, limitation, and show-value translation.
  • Quantitative evidence: pressure range, expansion ratio, leg angle, force, stiffness, hysteresis status, dome height, and double-dome resolution are now visible in the page table.
  • Visual evidence: cell geometry, pressure-dependent force/stiffness figure, module parts, module biasing, and physical object-manipulation motion.
  • Curve extraction would make the plotted force/stiffness/hysteresis data easier to inspect with uncertainty and test conditions.
