architecture

Cellular soft robotic architecture

One monolithically printed pneumatic cell reconfigured into planar morphing surfaces and cylindrical robot bodies.
Cell Monolithically printed pneumatic Sarrus-linkage-inspired unit with compliant links, flexural joints, and integrated PneuNet actuation.
Topology The same cell is grouped into modules, tiled as planar arrays, and rolled into cylindrical robot bodies.
Programs Actuation patterns select surface features, object interaction, continuum-style bending, crawling, and rolling.

cell

Cell and module behavior

  • Pressure-driven expansion rotates the linkage legs while the soft pneumatic chamber supplies the deformation.
  • The capped and uncapped cells are compared in the same operating range, so the geometry change is visible before topology-level behavior is introduced.
  • The force-displacement plots separate single-cell response from the 3 x 3 array, keeping load-bearing behavior distinct from the motion demonstrations.

build

Physical module and test state

  • The module photographs show the printed parts and snap-fit assembly rather than a purely rendered concept.
  • Compression images document how the unit and array behave under load before the page moves to surface programs.
  • The public system remains pneumatically tethered; electronically addressed actuation is still outside this build state.

motion

Programmed surface and body motion

  • The planar figures are limited to one height-map example and one object-transport example, instead of repeating similar wave panels.
  • The cylindrical figures show the same cell architecture rewrapped into bending and locomotion assemblies.
  • The selected set moves from local pressure pattern to measured surface shape to body-scale motion.
